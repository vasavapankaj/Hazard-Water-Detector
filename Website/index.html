About This IoT Project

This automated system utilizes an ESP32 microcontroller to monitor water quality in real-time. It actively reads data from multiple specialized sensors to ensure the water is safe for consumption or specific industrial applications.

ESP32 Microcontroller

Acts as the core processing unit, connecting to Wi-Fi to push sensor data to our MySQL database continuously via a PHP API endpoint.

TDS Sensor

Measures Total Dissolved Solids to indicate the concentration of dissolved substances in the water, helping identify contamination levels.

Turbidity Sensor

Measures the cloudiness or haziness of a fluid caused by large numbers of individual particles that are generally invisible to the naked eye.
